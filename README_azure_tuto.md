# Tutorial: Creación de Cuenta en Azure for Students

Este documento describe el paso a paso para crear una cuenta en la nube pública de **Microsoft Azure**, específicamente utilizando el beneficio de **Azure for Students**, la plataforma seleccionada para alojar y desplegar el proyecto PokeDex.

## Requisitos Previos

* Un correo electrónico institucional activo  en este caso el que se nos fue asignado por el Tecnológico Comfenalco.

* Un número de teléfono móvil para verificación de identidad.

## Procedimiento Paso a Paso

### Paso 1: Acceder al portal de la oferta

1. Abrimos el navegador y dirigimos  a la página oficial de [Azure for Students](https://azure.microsoft.com/es-es/free/students/).

2. En la pantalla principal, hacemos clic en el botón que dice **Empezar gratis**

### Paso 2: Autenticación institucional

1. Seremos redirigido a la página de inicio de sesión de Microsoft.

2. Ingresaremos con el **correo  institucional** y presionamos "Siguiente".

3. Ingresamos la contraseña de la cuenta universitaria.

### Paso 3: Registro y verificación del perfil

1. Al detectar el dominio educativo, Microsoft validará automáticamente la elegibilidad del correo.

2. Seremos dirigido a un formulario de registro. Completaremos los campos solicitados con los datos personales (Nombre, Apellidos, País, y Teléfono).

3. Marcamos las casillas para aceptar el acuerdo de suscripción, los detalles de la oferta y la declaración de privacida(En este caso fue gratis).

4. Hacemos clic en **Registrarse**

En este caso como  utilizamos una cuenta de  azure for students no requiere ingresar ninguna tarjeta de crédito.

> 

### Paso 4: Acceso al panel de control

1. Esperamos unos segundos para la  validación, y el sistema confirmará que la cuenta se ha configurado correctamente y que los créditos estudiantiles han sido asignados.

2.  por ultimo ya podemos  ir al portal de Azure  e ingresar la inicio (o ingresar manualmente a [portal.azure.com](https://portal.azure.com)).

3.  El entorno quedo listo. Desde este panel principal es posible comenzar a aprovisionar los recursos en la nube, como el servicio **App Service** utilizado para desplegar esta aplicación.
